<objective>
Build Spotify Now Playing and GitHub Activity widgets with API integration.

Purpose: Auto-updating "alive signals" that make the site feel dynamic without content debt.
Output: Two widgets that pull live data and display it elegantly.
</objective>

<context>
Spotify: Uses Spotify Web API to get currently playing / recently played.
  - Requires OAuth refresh token flow (client_id, client_secret, refresh_token in env)
  - API route proxies to avoid exposing tokens client-side
  - Lee Robinson's implementation is the reference pattern

GitHub: Uses GitHub REST API or GraphQL for contribution data.
  - Can use public API (no auth needed for public repos)
  - Show recent commits or contribution streak
  - GITHUB_TOKEN env var for higher rate limits

Both widgets should work even if API keys aren't configured (graceful fallback/empty state).
</context>

<task type="auto">
  <name>Task 1: Spotify Now Playing widget</name>
  <files>src/lib/spotify.ts, src/app/api/spotify/route.ts, src/components/widgets/spotify.tsx</files>
  <action>
    1. Create src/lib/spotify.ts:
       - Functions: getAccessToken (refresh_token → access_token), getNowPlaying, getRecentlyPlayed
       - Uses SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRET, SPOTIFY_REFRESH_TOKEN from env
       - Token refresh using client credentials + refresh token (base64 encoded)
       - Handle rate limits and errors gracefully
    2. Create src/app/api/spotify/route.ts:
       - GET handler that calls getNowPlaying, falls back to getRecentlyPlayed
       - Returns: { isPlaying, title, artist, album, albumImageUrl, songUrl } or null
       - Cache-Control: revalidate every 60 seconds
       - If env vars missing, return { isPlaying: false, error: "not_configured" }
    3. Create src/components/widgets/spotify.tsx:
       - Client component that fetches from /api/spotify
       - Polling: refetch every 30-60 seconds (use setInterval or SWR)
       - Display:
         - Small album art thumbnail
         - Track name + artist
         - "Now Playing" or "Recently Played" indicator
         - Spotify green accent color
         - Animated equalizer bars if playing (CSS animation)
       - Fallback: "Not playing" or hide widget entirely
       - Loading state: skeleton or subtle placeholder
    4. Place widget in hero section or footer (wherever it fits best)
  </action>
  <verify>API route returns track data (or graceful empty), widget renders</verify>
  <done>Spotify widget shows current/recent track with album art and artist</done>
</task>
