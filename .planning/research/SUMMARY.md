*A Comprehensive Investigation by S. Holmes*

**Subject:** Personal website redesign for Duane Cilliers
**Current State:** Minimal, outdated — mentions "Frontend Developer" at reOS (no longer accurate)
**Objective:** Transform into a living personal brand hub that captures the dev→entrepreneur narrative
**Date:** 2026-02-02

## Part I: Deep Analysis of kitze.io

### Site Structure (top to bottom)
- **Hero** — "Hi, I'm Kitze" with rotating subtitle: Developer / Creator / Educator. One-liner + location. Sets tone immediately
- **Speaker** — Tour section with upcoming/past talk locations. Visual proof of activity
- **YouTube Studio** — Category tabs (Dev, Work, Tech, Music, News) + featured video embed + 7 channel links. This is a CONTENT HUB
- **Startups & Code** — 4 major products (Sizzy, Benji, Sotto, Zero To Shipped) with descriptions + links. Then "Experiments & Side Projects" — 10 smaller projects as compact link cards
- **Writer** — Blog posts with dates, titles, viral tags, descriptions. Archive link

### What Makes It Work
- **Categorized chaos** — massive output organized into digestible sections
- **Two-tier project display** — major products get full cards, experiments get compact links. This hierarchy tells visitors what to care about
- **Active signals everywhere** — tour dates, featured videos, recent posts all scream "this person ships"
- **Personality** — not corporate, not tryhard. Confident and casual
- **Single page hub** — everything on one scrollable page. No maze of subpages

### Key Design Observations
- **Dark theme** with clean typography — feels modern/developer-native
- **No traditional portfolio grid** — it's a personal brand hub, not a showcase
- **Links are the currency** — every section links OUT to products, channels, posts. The site is a launchpad, not a destination
- **Viral social proof** — blog posts tagged "Viral" signal credibility
- **YouTube as first-class content** — embedded video + channel links gives visitors something to DO on the page

### Critical Takeaway for Duane
Kitze works because he has VOLUME — 7 YouTube channels, 4 startups, 10 side projects, speaking gigs, viral blog posts. You can't copy this structure 1:1 with less content. The trick is capturing the ENERGY (alive, shipping, multi-dimensional human) while adapting for a different content reality.

**You need the hub architecture without the content debt.**

## Part III: Section Recommendations for Duane

## Part IV: Content Strategy — Making It Feel Alive Without Content Debt

The biggest risk: launching a beautiful site that goes stale in 3 months. Here's how to prevent that:

### 🟢 Quick Wins (Day 1)
- Spotify "Now Playing" widget — auto-updating, zero effort
- GitHub contribution graph or recent commits
- "Last updated" timestamp on the /now section
- Photo from your latest surf/BJJ/3D print

### 🟢 Low-Maintenance Sections
- **/uses** — update once a year when you change gear
- **Hobbies section** — static icons/photos, update rarely
- **Project cards** — add a new one when you ship something (2-3x/year)
- **About page** — rewrite when your story changes (annually)

### 🟡 Medium Effort (Monthly)
- **/now section** — 5-minute update on what you're working on
- **One blog post per month** — even short "notes" count
- **Project screenshots** — swap in fresh ones when UI changes

### 🔴 Avoid These Content Traps
- A "weekly newsletter" you won't maintain
- A podcast section with 2 episodes from 2023
- Empty categories that signal abandoned ambitions
- "Coming soon" on anything

### Dynamic Elements That Add Life Automatically
- **Spotify Now Playing** — API integration, shows current/recent track. Lee Robinson does this. Dead simple with Next.js API routes
- **GitHub Activity** — Show recent commits or contribution graph via GitHub API
- **Latest Blog Post** — Auto-pulls to homepage from your MDX content
- **Photo of the week** — Pull from Instagram API or manual upload (surfing/3D prints)
- **"Reading" shelf** — Current book with cover image. Update when you finish one
- **Status badge** — "🟢 Available for freelance" or "🔴 Fully booked" — tiny but powerful signal

### Content Starter Pack (Launch with these 3 posts)
1. "Rebuilding my personal site with Next.js" — meta but effective, shows process
2. "From employee to freelancer: my first year" — narrative, personal, shareable
3. "What I use: my developer setup in 2026" — easy to write, evergreen traffic

**The Golden Rule:** Better to have 3 polished sections than 8 half-empty ones. You can always add sections later. Ship lean.

## Part V: Tech Stack Recommendations

### Framework: Next.js 15 (App Router)
- You already know it. Ship fast
- App Router with Server Components for performance
- React Server Components for blog content rendering
- API routes for dynamic widgets (Spotify, GitHub)

### Content Management — RANKED

**1. MDX + Content Collections (RECOMMENDED)**
- MDX files in your repo → type-safe content
- Contentlayer is DEPRECATED — use **Content Collections** (https://www.content-collections.dev/) or **Velite** (https://velite.js.org/) instead
- Fumadocs also has native Content Collections support
- **Pros:** Git-based, type-safe with Zod, zero vendor lock-in, works perfectly with Next.js
- **Cons:** Need to commit files to publish (fine for a personal site)

**2. Notion as CMS (ALTERNATIVE)**
- Write in Notion, pull via API, render in Next.js
- Great DX for writing — you probably already use Notion
- Library: `react-notion-x` or the official Notion API
- **Pros:** Write anywhere, familiar UI, good for non-devs
- **Cons:** API rate limits, formatting quirks, dependency on Notion

**3. Sanity (OVERKILL for personal site)**
- Great CMS but adds complexity you don't need
- Better for client projects (REW, TMG) than your personal blog
- Free tier is generous though

### Hosting: Vercel (RECOMMENDED)
- First-class Next.js support (they build it)
- Free tier is perfect for a personal site
- Preview deployments, analytics, edge functions
- Alternatives: Cloudflare Pages (cheaper at scale, great perf), Netlify (solid but no advantage over Vercel for Next.js)

### Styling: Tailwind CSS + shadcn/ui
- Tailwind for utility-first styling (you already know it)
- shadcn/ui for accessible, customizable components
- Dark mode support built-in

### Animation Libraries — RANKED

**1. Framer Motion (RECOMMENDED)**
- Best React integration — declarative, composable
- Perfect for: page transitions, scroll animations, hover effects, layout animations
- `AnimatePresence` for mount/unmount transitions
- Easy learning curve for a React dev

**2. GSAP (for advanced needs)**
- More powerful timeline control, ScrollTrigger plugin
- Better for complex scroll-based storytelling
- Heavier, more imperative — requires cleanup in React
- Use ONLY if Framer Motion isn't enough

**3. CSS-only (for micro-interactions)**
- `@starting-style` for entry animations (new CSS feature!)
- `linear()` timing function for spring physics
- Use for hover states, subtle transitions — no library needed

### Recommended Stack Summary
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS + shadcn/ui
- **Content:** MDX + Content Collections (or Velite)
- **Animation:** Framer Motion
- **Hosting:** Vercel
- **Analytics:** Vercel Analytics or Plausible (privacy-friendly)
- **Images:** Next/Image + Cloudinary (or Vercel's image optimization)
- **Fonts:** `next/font` with a distinctive typeface (Inter is safe, but consider JetBrains Mono for code vibes, or something like Satoshi/General Sans for personality)
- **OG Images:** `@vercel/og` for dynamic social preview images
- **RSS:** Built-in feed for blog posts

## Part VI: Differentiation — How to Capture Kitze Energy Without Being a Clone

The problem: Kitze.io works because Kitze has 10+ years of visible output. Copying the structure with less content = sad, empty website.

### Duane's Unique Angles

**1. The "Dev → Entrepreneur" narrative**
- This is your story arc. Most dev portfolios are static snapshots — yours can be a JOURNEY
- Frame everything through this lens: "I code AND I build businesses"
- The homepage should make this transition feel intentional, not accidental

**2. Cape Town / South Africa 🇿🇦**
- International devs are curious about tech scenes outside Silicon Valley
- Subtle local flavor: "Shipping code between surf sessions in Cape Town"
- This differentiates you from 10,000 Bay Area developer sites

**3. AI + Real Estate = REPE**
- This is a FASCINATING niche. Most devs build todo apps
- Feature REPE prominently with before/after staging images
- The visual nature of virtual staging means you can show, not just tell
- Interactive demo on your homepage? "See what AI staging looks like" → instant engagement

**4. Physical hobbies in a digital world**
- Surfing + BJJ + drums + 3D printing = extremely well-rounded human
- Most developer sites are 100% digital. Yours has physicality
- A photo grid of waves, 3D prints, and gi shots says "I live in the real world"
- These hobbies are VISUAL — use photos, not just icons

**5. The Maker Identity**
- 3D printing + coding + building products = MAKER
- "I make things. Sometimes with code. Sometimes with plastic. Always with intention."
- This is a stronger brand than "Full-Stack Developer"

### Design Differentiation Tactics
- **Don't go ultra-minimal** (too many devs already do this). Go for warm, personal, slightly playful — like Craftz.dog
- **Use one signature visual element** — a custom illustration, a 3D object, a distinctive color palette
- **Micro-interactions matter more than flashy animations** — cursor effects, hover states, smooth page transitions
- **Dark mode as default** (developer-native) with a light mode toggle
- **Custom OG image** that's instantly recognizable when shared on social media
